# Learning & Development Analytics – Power BI

A Power BI analytics project focused on evaluating employee training
effectiveness, performance improvement, training investment, completion
rates, employee engagement, and training ROI.

## Project Overview

This dashboard analyzes Learning & Development data to understand:

- Training effectiveness
- Employee performance improvement
- Training completion
- Training investment
- Training ROI
- Employee engagement
- Delivery mode effectiveness
- Department-level performance

## Dashboard Pages

### Page 1 – Overview
Provides a high-level view of training performance using KPIs and
business-level visualizations.

### Page 2 – Methods & Strategies
Analyzes how training methods, delivery modes, programs, and departments
relate to performance and ROI.

### Page 3 – Conclusions
Summarizes key insights, recommendations, root cause analysis (RCA),
and SWOT analysis.

## Tools & Technologies

- Power BI
- DAX
- Data Visualization
- Data Analysis
- Microsoft Excel/CSV

## Key KPIs

- Employees Trained
- Completion Rate
- Training Investment
- Average Performance Gain
- Average ROI
